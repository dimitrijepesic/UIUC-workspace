## 1. Which experiments/notes already dealt with lstsq / gelsd / gels / pinv / SVD / closed form, and what did each find?

### Takeaway
The workspace has a long, consistent paper trail: (1) per-neuron `gelsd` was batched into one `gelsd` call per layer (bit-identical, Phase 5-6); (2) CUDA `gels` was measured to be catastrophically wrong on rank-deficient boxes (errors of 1e15-1e34 on an A100), so `gelsd` was kept on CPU in the hybrid; (3) once splits were batched, CPU `gelsd` became 65-88% of the batched `big` pass; (4) a closed-form (diagonal normal equations + exact min-norm degenerate branches) prototype was written and checked on CPU real data on 25.10.2026 but lives only in a private note, not in the repo. `pinv`/SVD on GPU has never been run or timed anywhere; earlier sprint docs explicitly *rejected* closed-form/normal-equations/pinv (before the batched-splits bottleneck existed).

### Inferences
- The 15-34-orders-of-magnitude `gels` failure is directly relevant to every run, not just edge cases: layer 1 is rank-2 (y constant) for all boxes, so any GPU solver must reproduce the min-norm split between `C` and `B*y0` (the closed-form branch `C = k/(1+y0^2)`, `B = k*y0/(1+y0^2)`), not just "drop the column".
- The earlier "closed form: NO" verdict was made when batched `gelsd` was ~1-5% of the run and bit-exactness was the bar; its two reasons ("unnecessary", "squares the condition number") are now partly obsolete (it is 65-88% of batched big) and partly addressed (the prototype does not form a 3x3 Gram matrix; the orthogonal-grid structure makes it diagonal). A reviewer should still weigh the condition-number concern for near-degenerate boxes (R3 in the note).
- `gelsd` cost is ~8 µs per 25x3 problem on Colab CPU (≈2200.7 ms / (64·4·1024) problems), consistent with the per-layer 7-8.6 ms for 1024 problems; it scales linearly with S, which is why batching doesn't help.
- Driver-difference magnitude reference point: `gelsy` vs `gelsd` on realistic grids differs up to ~4.4e-12 relative per coefficient (M10 log), far below the 1e-10 per-split test tolerance but above the 1e-12 unit-test tolerance.
